# Lexique de Valderaan

Page de consultation du Lexique du serveur Garry's Mod RolePlay **Valderaan** : les mots du monde et du jeu, définis en une ou deux phrases.

- **Page en ligne** : publiée par GitHub Pages depuis la branche `main`.
- **Source unique** : la note `00_CANON_Lexique` du coffre *Valderaan - Bible Visuelle*. Le bloc `<script id="source">` de `index.html` en est une copie exacte. Il est régénéré depuis la note et n'est jamais retouché à la main.

## Mettre à jour

1. Remplacer le contenu du bloc `source` dans `index.html` par les entrées de la note, en changeant `version` et `date`.
2. Faire un commit avec pour message « Lexique vN — ce qui change ».
3. La page en ligne se met à jour en une à deux minutes.

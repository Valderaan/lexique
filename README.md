# Lexique de Valderaan

Page de consultation du Lexique du serveur Garry's Mod RolePlay **Valderaan** : les mots du monde et du jeu, et les figures du Royaume, définis en une ou deux phrases.

- **Page en ligne** : https://valderaan.github.io/lexique/ — mode jeu, pour le menu TAB : https://valderaan.github.io/lexique/?jeu
- **Source unique** : la note `09 - Récits et points de vue/00_CANON_Lexique_v1` du coffre *Valderaan - Bible Visuelle*. Le bloc `<script id="source">` de `index.html` est une copie exacte de sa section « Entrées ». On ne le retouche jamais à la main.
- **Étiquettes reconnues** : Monde, Jeu, Figures, Bestiaire. Un bouton de filtre sans entrée reste masqué.

## Mettre à jour

1. Copier la section « Entrées » de la note (lignes `version:`, `date:`, `maquette:` comprises) dans le bloc `source` de `index.html`.
2. Faire un commit avec pour message « Lexique vN — ce qui change ».
3. La page en ligne se met à jour en une à deux minutes (onglet *Actions*).
